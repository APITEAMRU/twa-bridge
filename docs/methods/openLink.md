## Метод `openLink`
### web_app_open_link

### Описание
Метод, который открывает ссылку во внешнем браузере. Мини-приложение не будет закрыто.

### Требования
Минимальная версия Telegram API: 6.2+

### Поддержка платформ
- Telegram Web
- Telegram Desktop
- Telegram Mobile (iOS/Android)

### Использование
```javascript
// Использование системного цвета
bridgeOpenLink({ url: "https://t.me/apiteamru" })
```

### Параметры
| Параметр         | Тип     | Описание                                                                                                 |
| ---------------- | ------- | -------------------------------------------------------------------------------------------------------- |
| url              | string  | URL-адрес, который должен быть открыт приложением Telegram. Должен быть полным путем с протоколом https. |
| try_instant_view | boolean | [v6.4] Необязательно. Ссылка будет открыта в режиме мгновенного просмотра, если это возможно.            |
| try_browser      | boolean | [v7.6] Необязательно.                                                                                    |

### Возвращаемое значение
```typescript
{
  status: boolean | 'not_supported'
}
```
